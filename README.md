# Yazan Nasr — Portfolio

> Refined portfolio build with responsive project preview framing and direct WhatsApp contact.

A responsive static portfolio website for **Yazan Nasr**, Computer Engineer and Flutter & Full-Stack Developer.

## Included

- Responsive portfolio landing page
- About, projects, toolkit, approach and contact sections
- Six current public GitHub projects
- Project filtering by technology/theme
- Project case-study modal with GitHub links
- Light/dark theme toggle
- Mobile navigation
- Scroll reveal animations and back-to-top control
- Local profile photo and CV image
- No framework or build step required

## Run locally

Open `index.html` directly in a browser, or serve the folder with a simple local server.

Example:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Deploy on GitHub Pages

1. Create a repository named `yazannasr288.github.io` under the GitHub account `yazannasr288`.
2. Copy the contents of this folder into that repository.
3. Push to the `main` branch.
4. In GitHub: **Settings → Pages → Build and deployment → Deploy from a branch → main / root**.
5. GitHub Pages will publish the site at `https://yazannasr288.github.io/`.

The project uses public GitHub image URLs for project screenshots so the portfolio can stay lightweight while keeping the screenshots tied to their original repositories.
